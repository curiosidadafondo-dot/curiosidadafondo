Política de privacidad

Última actualización: 5 de noviembre de 2026.

Quién somos

Esta política describe la aplicación «Curiosidad a Fondo (subidas)», una herramienta privada de uso propio del canal de YouTube Curiosidad a Fondo. La utiliza únicamente el propietario del canal. Contacto: curiosidadafondo@gmail.com.

Qué hace la aplicación

Sube y programa los vídeos del propio canal del propietario mediante la API de YouTube (YouTube Data API v3). Para ello solicita, con el consentimiento del propietario a través de Google, los permisos youtube.upload (subir vídeos) y youtube.readonly (consultar el estado de los vídeos del propio canal).

Qué datos se usan y cómo

  • La aplicación no recopila datos personales de espectadores ni de ningún otro usuario.
  • Del propietario solo se guarda el token de acceso que Google emite al autorizar, en un servidor privado y con acceso restringido. Se usa únicamente para subir y consultar los vídeos del propio canal.
  • Los datos obtenidos de las API de Google no se venden, no se comparten con terceros, no se usan para publicidad ni para entrenar modelos de inteligencia artificial de terceros.
  • El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustarán a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Servicios de API de YouTube

Esta aplicación utiliza los servicios de API de YouTube. Al usarla, aceptas quedar sujeto a las Condiciones del servicio de YouTube y a la Política de privacidad de Google.

Cómo revocar el acceso y borrar los datos

El propietario puede revocar el acceso en cualquier momento en myaccount.google.com/permissions. Al revocarlo, el token deja de funcionar y se elimina del servidor. Para pedir el borrado de cualquier dato, escribe a curiosidadafondo@gmail.com.

Cambios

Si esta política cambia, se actualizará esta página con la nueva fecha.

Privacy policy

Last updated: November 5, 2026.

"Curiosidad a Fondo (subidas)" is a private, single-owner tool for the YouTube channel Curiosidad a Fondo. It uploads and schedules the channel owner's own videos through the YouTube Data API v3, using the Google OAuth scopes youtube.upload and youtube.readonly granted by the owner. Contact: curiosidadafondo@gmail.com.

  • The application does not collect personal data from viewers or any other users.
  • Only the owner's OAuth token issued by Google is stored, on a private server with restricted access, and used solely to upload and check the owner's own channel videos.
  • Data obtained from Google APIs is not sold, shared with third parties, used for advertising, or used to train third-party AI models.
  • The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • This application uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.
  • Access can be revoked at any time at myaccount.google.com/permissions; to request deletion of any data, contact curiosidadafondo@gmail.com.
